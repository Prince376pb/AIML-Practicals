# Practical 01 - PEAS Descriptors of Task Environment

## Problem Statement

Demonstrate PEAS Descriptors of Task Environment using Vacuum Cleaner Intelligent Agent Application.

## Description

This practical demonstrates the PEAS description of a vacuum cleaner intelligent agent using Prolog.

The environment contains three rooms: kitchen, hall and bedroom. The vacuum cleaner cleans the dirty rooms, moves between connected rooms and stops when all rooms are clean.

## Technology Used

- Prolog
- SWI-Prolog
