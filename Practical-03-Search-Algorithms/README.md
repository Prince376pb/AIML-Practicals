# Practical 03 - Search Algorithms

## Problem Statement

Evaluate the performance of various algorithms (Uninformed, Informed, Local Search and Constraint Satisfaction) of problem solving through Search.

## Objective

- To implement different search algorithms.
- To understand Uninformed, Informed, Local Search and Constraint Satisfaction techniques.
- To compare the algorithms based on nodes explored, path cost and execution time.

## Algorithms Used

1. BFS - Breadth First Search
2. DFS - Depth First Search
3. A* Search
4. Hill Climbing
5. Backtracking

## Description

In this practical, different search techniques are implemented using Python.

BFS and DFS are used as Uninformed Search algorithms. A* Search is used as an Informed Search algorithm. Hill Climbing is used for Local Search and Backtracking is used for solving a Constraint Satisfaction Problem.

The algorithms are evaluated using the path obtained, number of nodes explored, path cost and execution time.
