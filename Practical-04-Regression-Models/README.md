# Practical 04 - Regression Models

## Practical Title
Regression Models for House Price Prediction and Gradient Descent Optimization

## Problem Statement
1. Develop regression models for a real-world application of house price prediction and evaluate the performance using appropriate metrics.
2. Implement and analyze the performance of Gradient Descent optimization for Linear Regression.

## Models Used
- Linear Regression
- Decision Tree Regression
- Random Forest Regression
- Gradient Descent for Linear Regression

## Performance Metrics
- MAE
- MSE
- RMSE
- R2 Score

## Technology Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The house price dataset is generated using Python code.

## Output
The program generates model performance results, house price predictions, and graphs for performance analysis.
