# Practical 02 - Library Book Recommendation Expert System

## Problem Statement

Develop a Prolog-based Expert System that recommends suitable books based on the user's genre, reading level, and subject preferences.

## Description

This practical implements a simple library book recommendation expert system using Prolog.

The system takes the user's genre, reading level and subject preferences and recommends a suitable book based on the available book information.

## Technology Used

- Prolog
- SWI-Prolog
