# Practical 05 - Classification Models

## Practical Title
Classification Models and Performance Analysis

## Problem Statement
Develop classification models using SVM, Decision Tree, KNN, and Naive Bayes. Evaluate their performance using accuracy, precision, recall, F1-score, and loss, and compare the results.

## Dataset
The Breast Cancer dataset provided by Scikit-learn is used. It contains 569 records, 30 features, and two classes: malignant and benign.

## Models Used
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Performance Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Log Loss

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Results
The four classification models are trained and evaluated using the same test dataset. SVM achieved the highest F1-score of 0.9825 in this experiment.
